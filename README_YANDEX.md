# Slime Rush — сборка и публикация в Яндекс Играх

Название игры — **Slime Rush** (в `project.godot`, в меню и во всех экранах).
Слово «Mario» в проекте не встречается (п. 5.12 и 3.6 чек-листа).

## 2. Геймплей

**Управление.** Клавиатура: `A/D` или `←/→`, `W`/`Space`/`↑` — прыжок, `J` — выстрел,
`1..4` — бустеры, `Esc` — пауза. На тач-экранах автоматически появляются четыре крупные
кнопки (64x64 px): влево, вправо, прыжок, выстрел, плюс кнопки паузы `II` и фуллскрина `[ ]`
в верхнем углу и иконки бустеров (тап по иконке = применить).

**Бустеры** (находятся на уровнях и покупаются в магазине):

| Бустер | Действие |
|---|---|
| Звезда | бессмертие 8 сек, враги и босс получают урон от прикосновения |
| Пружина | прыжок −400 → −520 на 20 сек |
| Гриб | рост: первый удар только уменьшает, второй снимает жизнь |
| Огнемет | 12 выстрелов, убивает любых врагов, включая шипастых, и бьёт босса |

**Две валюты.** Монеты — за сбор и за уровень (+10). Трофеи — только за убийства:
обычный враг = 1, босс = 5. На трофеи покупаются бустеры и улучшение «старт в большой форме».

**Магазин:** жизнь (60 монет), 4 бустера (5–10 трофеев), 3 героя-скина (150/250/400 монет),
постоянные улучшения: 4 жизни на старте (300), магнит монет (220), старт в большой форме (18 трофеев).

**Ачивки:** 12 штук по накопительной статистике (уровни, убийства 10/50/200, монеты 100/500,
боссы 1 и 4, уровень без урона, 5 бустеров, первая покупка, вся игра). При получении — всплывашка в HUD.

**Враги:** слизни с 1 уровня, улитки (2 hp) с 3-го, шипастые (не топчутся) с 6-го.
**Пчёлы** — с 3 уровня: `1 + (уровень − 3) / 2`, максимум 6 (т. е. 3 ур. — 1 пчела, 5 ур. — 2,
7 ур. — 3 и так далее), летают по синусу на высоте 5–6 ряда.
**Боссы** — каждый 3-й уровень, флаг на выходе открывается только после победы.

## 3. Мобильная адаптация (п. 1.10)

- виртуальное разрешение 640x360, `stretch/mode=canvas_items`, `aspect=keep` — интерфейс не едет
  ни на 16:9, ни на 20:9, ни на 4:3;
- `window/handheld/orientation="landscape"` — только альбомная ориентация;
- при вызове фуллскрина JS дополнительно пробует `screen.orientation.lock("landscape")`;
- все кнопки не меньше 32 px, игровые — 64 px;
- в меню в `Web`-пресете отключены потоки — игра запускается без SharedArrayBuffer,
  что важно для мобильных браузеров.

## 5. Экспорт в Web и патч

1. `godot --path C:\Neiralab\slime -e` → `Editor → Manage Export Templates → Download and Install`.
2. `Project → Export` — пресет `Web` уже в `export_presets.cfg`, путь `build/index.html`,
   `Thread Support` и `Extensions Support` выключены.
3. `Export Project`.
4. Патч и архив:

```powershell
cd C:\Neiralab\slime
powershell -ExecutionPolicy Bypass -File .\_bin\patch_yandex.ps1
```

## 6. Чек-лист Яндекс Игр — что где закрыто

### SDK и инициализация

| Пункт | Где |
|---|---|
| 1.1 SDK из официального источника | `<script src="/sdk.js">` до `YaGames.init()` |
| 1.19.2 Game Ready API | `Ya.game_ready()` → `LoadingAPI.ready()`, вызов один раз из любого экрана |
| 2.14 язык интерфейса | `i18n.gd` берёт `ysdk.environment.i18n.lang`, фолбек — локаль OS |
| 1.14 запуск в черновике | сделаешь сам после загрузки архива |

### Техническое качество

| Пункт | Где |
|---|---|
| 1.14 загрузка без зависания | нет внешних запросов, все ассеты в архиве |
| 1.14 нет JS-ошибок | весь SDK-код в `try/catch`, без SDK игра работает |
| 1.15 без фризов | `gl_compatibility`, nearest-фильтр, без шейдеров и тяжёлых узлов |
| 1.9 сохранение прогресса | `ConfigFile` + `player.setData/getData` через `getPlayer()` |
| 1.10 масштабирование | см. раздел 3 |

### Интерфейс

| Пункт | Где |
|---|---|
| 1.6 нет контекстного меню | `document.addEventListener("contextmenu", preventDefault)` |
| 1.6 видео во встроенном плеере | видеоконтента в игре нет |
| 1.3 звук паузится без фокуса | `visibilitychange`/`blur` + `game_api_pause` → `window.nlPaused` → `Sfx` мьютит шину и `pause.gd` ставит `get_tree().paused` |

### Реклама

| Пункт | Где |
|---|---|
| 4.7 звук паузится на ролике | коллбеки `open/close/error` ставят `nlPaused` |
| 4.4 только в логических паузах | `showFullscreenAdv` только в `next_level()` и на экране проигрыша |
| 4.5 явное согласие на rewarded | `adbox.gd`: диалог ·СМОТРЕТЬ / ОТМЕНА·, `showRewardedVideo` только после нажатия |

Бонусы за рекламу: в меню и магазине — «РЕКЛАМА: +75 МОНЕТ», на экране проигрыша —
«РЕКЛАМА: +1 ЖИЗНЬ» с продолжением уровня.

Добавь `&debug-mode=16` к URL черновика: в панели индикатор `IT` подтверждает,
что `LoadingAPI.ready()` прилетел. Если не горит — реклама и метрики не работают.
